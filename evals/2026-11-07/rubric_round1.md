# FPCOS evaluation rubric (fixed before reading any answer)

Score each answer on each criterion: 2 = clearly met, 1 = partly, 0 = not met.
FPCOS promises to reduce hallucination; A1-A3 measure that directly. A good answer without any skill can score full marks.

A1 Factual accuracy - every factual claim is correct. You MAY use web search to check specific claims (names, numbers, citations, studies). 2 = no errors found, 1 = minor error, 0 = a material false claim.
A2 No fabrication - no invented numbers, citations, studies, quotes or specifics presented as fact. Estimates are fine only if labelled as estimates with their basis. 0 if any fabricated citation or figure is stated as fact.
A3 Premise check - spots and corrects a false, loaded or absolutist premise in the question (F1, F4 have one; for prompts without one, 2 = does not invent a false premise or accept an unstated assumption uncritically).
A4 Known / inferred / unknown - makes clear what is established, what is inferred, and what is not known.
A5 Calibrated confidence - certainty matches the evidence; no precise confidence number that the evidence cannot support; firm where the fact is firm (e.g. F7).
A6 Alternatives - considers other explanations or options where they matter (2 also when the question has a single settled answer and none are needed).
A7 Root cause - addresses the cause rather than the symptom where relevant (F5, F6); elsewhere, answers the actual question asked.
A8 What would change it - names conditions or evidence that would change the answer, where relevant (2 if not relevant, e.g. F7).
A9 Usefulness - a reader can act on it or knows exactly what they now know.
A10 Proportion - length and structure fit the question. A one-line fact (F7) answered with a framework scores 0.
